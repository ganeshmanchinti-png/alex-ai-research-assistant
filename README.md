# 🤖 Alex AI Research Assistant

An AI-powered Research Assistant that helps users find answers using PDF documents and Web Search.

## 🚀 Live Demo

**[👉 Click Here to Open Alex AI Research Assistant](https://alex-ai-frontend.onrender.com)**

## ✨ Features

- 📄 Upload PDF documents and ask questions.
- 🌐 Search the web and get AI-powered answers.
- 🤖 AI-powered responses using Groq API.
- 🔍 Web search powered by Tavily API.
- 💬 Interactive chat interface.

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- CSS
- Vite

**Backend**
- Node.js
- Express.js
- Groq API
- Tavily API
- PDF Processing
